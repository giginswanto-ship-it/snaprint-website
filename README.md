## ✨ Fitur Utama
1. **Katalog Produk Dinamis:**
   - Filter Kategori (*Outdoor & Banner, Stiker & Label, Promosi & Kartu, Cetak Dokumen/Buku, Merchandise & Packaging*).
   - Live Search produk berdasarkan nama dan spesifikasi bahan.
   - Filter status ketersediaan (*Tersedia / Pre-Order*).

2. **Kalkulator Estimasi Biaya Cetak Online:**
   - Perhitungan otomatis untuk banner/spanduk berdasarkan luas meter persegi ($\text{m}^2$) dari input dimensi panjang & lebar (cm).
   - Perhitungan quantity untuk produk lembaran / box / pcs.
   - Tambahan opsi finishing (*Laminasi Glossy/Doff, Mata Ayam/Ring Banner, Kiss-Cut / Die-Cut, Jilid Buku*).
   - Tombol **"Pesan via WhatsApp"** dengan format pesan otomatis yang rapi ke admin hotline.

3. **Mode Owner (Protected Area - PIN: `1234`):**
   - Mengubah HPP modal, harga jual, margin keuntungan secara langsung di tabel.
   - Mengubah status ketersediaan produk.
   - Menambahkan produk baru & menghapus produk.
   - Data otomatis tersimpan di `localStorage` peramban.

4. **Panduan File Siap Cetak (Preflight Guide):**
   - Checklist standar warna CMYK, resolusi minimal 300 DPI, penambahan bleed, serta format file yang didukung (*PDF, TIFF, CDR, AI*).
